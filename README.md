## 🔧 Requirements

### Essential Mod
You **MUST** have **EnzoModMenu** installed and configured:

- Tutorial: [Installation Guide](https://youtu.be/cIVeSeSIT2I)

🚀 How to Use
Launch Phasmophobia in Windowed Mode, the cords in script is for 1360x768 you can change resolution in game or in script using cords.py to grab cords for buttons and put in main.py

Position the game window so it's fully visible


Press F8 anytime to stop the bot

❓ Troubleshooting
If the bot doesn't click properly:

Verify game resolution matches script settings

Disable any overlays (Discord/Steam)

Run both game and script as Admin

Check mod settings are enabled
